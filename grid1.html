Grid Workshop · EJ-01

justify-items / align-items / place-items

¿Qué ocurre cuando la caja es más pequeña que su celda?

Paso 1 — activa el tamaño

Para que justify-items tenga efecto, la caja debe ser más pequeña que su celda. Activa el interruptor y observa.

Añadir width: 80px; height: 60px
⚠ Sin tamaño fijo la caja se estira (stretch por defecto) y ocupa toda la celda. Las propiedades de alineación no tienen efecto visible.
Paso 2 — prueba los valores
justify-items
eje horizontal (dentro de la celda)
align-items
eje vertical (dentro de la celda)
CSS resultante
.contenedor {
  justify-items: stretch;
  align-items: stretch;
}

.caja {
  width: 80px;
  height: 60px;
}
Paso 3 — place-items

place-items es el shorthand de ambas propiedades:
place-items: <align-items> <justify-items>

valor qué hace
stretch La caja ocupa todo el ancho (o alto) de la celda. Es el valor por defecto.
start La caja se sitúa al inicio de la celda (izquierda en justify, arriba en align).
center La caja se centra dentro de la celda.
end La caja se sitúa al final de la celda (derecha o abajo).
Regla clave: justify-items y align-items solo tienen efecto visible cuando la caja es más pequeña que su celda. Si la caja se estira para llenar la celda (valor stretch), no hay espacio libre dentro de la celda y la alineación no cambia nada.
🎯 Reto — escríbelo tú

Crea un nuevo archivo reto-ej01.html con un grid de 4 columnas × 2 filas. Las celdas deben medir 120 × 100 px.
Consigue que todas las cajas queden pegadas abajo a la derecha de su celda, con un tamaño de 60 × 50 px.

/* punto de partida */
.contenedor {
  display: grid;
  /* ← 4 columnas de 120px */
  /* ← 2 filas de 100px */
  /* ← gap de 8px */
  /* ← alineación: abajo a la derecha */
}
.caja {
  background: #f59e0b;
  /* ← tamaño: 60 × 50px */
}
