Grid Workshop · EJ-02

justify-content / align-content / place-content

¿Cómo se distribuye el espacio libre entre las pistas del grid?

Diferencia clave

justify-content y align-content distribuyen el espacio libre entre columnas y filas, no dentro de las celdas.

Solo tienen efecto cuando las pistas tienen tamaño fijo (px, em…) y el contenedor es más grande que la suma de pistas + gaps.

justify-content (eje horizontal)
align-content (eje vertical)
CSS resultante
/* contenedor: 460×240px */
/* pistas: 3×100px + 2×8px = 316px */
/* libre H: 144px · libre V: 94px */

.contenedor {
  justify-content: start;
  align-content: start;
}
Shorthand: place-content

place-content: <align-content> <justify-content>

valorcómo reparte el espacio libre
startTodo el espacio al final. Las pistas se agrupan al inicio.
endTodo el espacio al principio. Las pistas se agrupan al final.
centerEspacio repartido a partes iguales antes y después del grupo.
space-betweenEspacio solo entre pistas. Sin margen en los extremos.
space-aroundEspacio igual a cada lado de cada pista. Extremos = ½ del hueco central.
space-evenlyEspacio exactamente igual entre pistas y en los extremos.
¿En qué se diferencia de justify-items?
justify-content mueve las columnas dentro del contenedor. justify-items mueve los elementos dentro de su celda. Son dos niveles distintos de alineación.
🎯 Reto — escríbelo tú

Crea un archivo reto-ej02.html con este grid:
• 5 columnas de 80px y 3 filas de 60px
• Contenedor de 600 × 300px

Consigue que las columnas queden distribuidas con espacio igual entre ellas y en los bordes, y las filas centradas verticalmente. Usa el shorthand place-content.

/* punto de partida */
.contenedor {
  display: grid;
  grid-template-columns: repeat(5, 80px);
  grid-template-rows: repeat(3, 60px);
  gap: 8px;
  width: 600px;
  height: 300px;
  /* ← place-content aquí */
}
