auto-fit + minmax() — galería responsive sin media queries

El grid ajusta automáticamente el número de columnas según el espacio disponible.

Concepto

repeat(auto-fit, minmax(MIN, 1fr)) crea todas las columnas que quepan con un mínimo de MIN píxeles. Cuando el contenedor se hace más estrecho, las columnas desaparecen y los elementos saltan a la siguiente fila — sin escribir ni una media query.

auto-fit vs auto-fill

auto-fit: colapsa las columnas vacías. Los elementos existentes se expanden para llenar todo el ancho.

Ajusta minmax()
Ancho mínimo de cada columna. Por debajo de este valor el elemento salta a la siguiente fila.

función / valorqué hace
minmax(200px, 1fr)Cada columna tiene mínimo 200px y máximo 1fr (reparte el espacio sobrante).
auto-fitCrea tantas columnas de al menos MIN px como quepan. Colapsa las vacías.
auto-fillIgual que auto-fit pero mantiene las columnas vacías (reserva el espacio).
gapEspacio entre filas y columnas. Se tiene en cuenta al calcular cuántas columnas caben.
La fórmula mágica para galerías responsive:
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr))
Una sola línea de CSS hace el trabajo de tres o cuatro media queries.

Crea reto-ej06.html con una galería de 10 fotos reales usando imágenes de Pexels o Unsplash:

  • Mínimo de columna: 240px
  • Ratio de cada foto: 3/2 (usa aspect-ratio)
  • Gap de 12px
  • Las fotos deben cubrir su celda sin deformarse (object-fit: cover)
  • Sin ninguna media query
.galeria {
  display: grid;
  /* ← repeat auto-fit minmax */
  /* ← gap */
}

  /* ← aspect-ratio, object-fit, width */
}
