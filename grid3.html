Grid Workshop · EJ-03

Números de línea — grid-column / grid-row

Coloca un elemento en posición exacta usando los números de las líneas del grid.

Concepto

CSS Grid numera sus líneas empezando en 1. Un grid de 4 columnas tiene líneas de columna 1 a 5. Con grid-column: inicio / fin le dices al elemento entre qué líneas debe colocarse.

También puedes usar números negativos: -1 es la última línea, -2 la penúltima, etc.

Elige el elemento
grid-column
Rango: 1 a 5 (o -5 a -1 desde el final)
grid-row
Rango: 1 a 4 (o -4 a -1 desde el final)
CSS resultante
/* Elemento A (rojo) */
.A {
  grid-column: 1 / 2;
  grid-row: 1 / 2;
}
/* Elemento B (naranja) */
.B {
  grid-column: 1 / 2;
  grid-row: 1 / 2;
}
/* Elemento C (morado) */
.C {
  grid-column: 1 / 2;
  grid-row: 1 / 2;
}

sintaxissignificado
grid-column: 1 / 3Desde la línea de col 1 hasta la línea de col 3 (ocupa 2 columnas).
grid-column: 2 / -1Desde la línea 2 hasta el final (línea -1 = última).
grid-row: 1 / 3Desde la línea de fila 1 hasta la 3 (ocupa 2 filas).
grid-column: 1 / 2Una sola columna. Equivale al valor por defecto (auto).
Recuerda: el número indica la línea, no la columna. Un elemento que va de la línea 1 a la 3 ocupa 2 columnas, no 3.
🎯 Reto — escríbelo tú

Crea un archivo reto-ej03.html con un grid de 3 columnas × 3 filas (celdas de 120 × 100px, gap 8px) y coloca tres elementos con estas posiciones exactas:

  • Elemento A — ocupa toda la primera fila (de col 1 a col 4)
  • Elemento B — columna 1, filas 2 y 3
  • Elemento C — columnas 2 y 3, fila 2
  • El resto de celdas se rellenan con divs neutros
/* punto de partida */
.contenedor {
  display: grid;
  /* ← 3 columnas de 120px */
  /* ← 3 filas de 100px */
  /* ← gap */
}
.A { /* grid-column y grid-row */ }
.B { /* grid-column y grid-row */ }
.C { /* grid-column y grid-row */ }
