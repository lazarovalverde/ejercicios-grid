Grid Workshop

Seis ejercicios interactivos para dominar CSS Grid paso a paso. Explora cada propiedad y consolida lo aprendido con el reto final.

EJ-01
Alineación de cajas dentro de la celda
justify-items align-items place-items
Descubre qué ocurre cuando la caja es más pequeña que su celda. Controla su posición en el eje horizontal y vertical.
Abrir ejercicio
EJ-02
Distribución de pistas en el contenedor
justify-content align-content place-content
Cuando las pistas tienen tamaño fijo, el contenedor puede tener espacio sobrante. Distribuye ese espacio libre entre columnas y filas.
Abrir ejercicio
EJ-03
Posición con líneas de grid
grid-column grid-row
Coloca cada elemento usando números de línea absolutos. Aprende a usar líneas negativas para contar desde el final.
Abrir ejercicio
EJ-04
La palabra clave span
span grid-column grid-row
Compara tres formas equivalentes de expresar el mismo span: línea/línea, línea/span y solo span con colocación automática.
Abrir ejercicio
EJ-05
Mapa de áreas
grid-template-areas grid-area
Dibuja el layout de la página con cadenas de texto. Asigna cada zona por nombre y observa el resultado en tiempo real.
Abrir ejercicio
EJ-06
Galería responsive sin media queries
auto-fit minmax() repeat()
Una sola línea de CSS ajusta automáticamente el número de columnas según el ancho del contenedor. Sin media queries.
Abrir ejercicio
