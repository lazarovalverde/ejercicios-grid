grid-template-areas — zonas con nombre

Define el layout de una página dibujándolo con texto en el CSS.

Concepto

Con grid-template-areas defines el layout como un mapa visual: cada celda del mapa contiene el nombre de la zona. Los elementos hijos se asignan con grid-area: nombre.

Un . (punto) deja la celda vacía.

Dibuja el layout (3 col × 4 fil)
header
nav
main
sidebar
footer
. (vacío)

Haz clic en cada celda para cambiar la zona.

reglafunción
grid-template-areasEn el contenedor. Define el mapa de zonas con strings entre comillas, uno por fila.
grid-area: nombreEn cada hijo. Le dice al elemento en qué zona debe colocarse.
. (punto)Celda vacía. No se le asigna ningún elemento.
Repetir nombreSi un nombre aparece en varias celdas contiguas, el elemento las ocupa todas (debe formar un rectángulo).
⚠ Las zonas deben ser rectángulos. No puedes tener una zona en forma de L o discontinua: el navegador ignorará el layout. Si ves que el resultado no cuadra, comprueba que cada nombre forma un bloque rectangular.
🎯 Reto — escríbelo tú

Crea reto-ej05.html con un layout de 2 columnas (1fr 3fr) × 3 filas usando grid-template-areas:

┌─────────────────────┐
│ header   header   │ ← fila 1: ocupa las 2 columnas
├──────┬──────────────┤
│ nav  │ main        │ ← fila 2
├──────┤              │
│ nav  │ main        │ ← fila 3
└──────┴──────────────┘
.contenedor {
  display: grid;
  /* ← grid-template-columns */
  /* ← grid-template-rows (3 filas de 80px) */
  /* ← grid-template-areas */
  gap: 8px;
}
.header { grid-area: header; }
.nav { grid-area: nav; }
.main { grid-area: main; }
